# كاشير المتجر - نسخة الاستضافة الخاصة

تطبيق كاشير يعمل على الهاتف، بقاعدة بيانات PostgreSQL دائمة، وبمسح باركود تلقائي بالكاميرا (الأمامية افتراضياً).
الكاميرا تعمل لأن الصفحة تُفتح مباشرة على دومين HTTPS خاص بك.

## المتطلبات
1. قاعدة PostgreSQL (من Render أو Neon أو Supabase أو أي مزوّد).
2. استضافة Node.js (مثل Render أو Railway) تعطيك رابط HTTPS.

## النشر على Render (مثال)
1. ارفع مجلد المشروع إلى مستودع GitHub.
2. في Render: New ← PostgreSQL، وانسخ Internal/External Database URL.
3. في Render: New ← Web Service، واختر المستودع.
   - Build Command: `npm install`
   - Start Command: `npm start`
4. أضف متغيرات البيئة:
   - `DATABASE_URL` = رابط قاعدة البيانات
   - `APP_PASSWORD` = كلمة مرور قوية (تُطلب عند أول فتح)
5. افتح رابط الخدمة في Chrome، وأضفه إلى الشاشة الرئيسية.

الجدول `docs` يُنشأ تلقائياً عند أول تشغيل.

## ملاحظات
- إذا كانت قاعدتك لا تدعم SSL محلياً، أضف `DATABASE_SSL=false`.
- خذ نسخاً احتياطية دورية من PostgreSQL، وتحقق من شروط الخطة المجانية لدى المزوّد قبل الاعتماد عليها لمتجر فعلي.
- كلمة المرور واحدة مشتركة لكل المستخدمين.
